# Atlântico — Controle de Atividades V1

Aplicativo web estático para GitHub Pages.

## Como publicar
1. Crie um repositório no GitHub.
2. Envie `index.html` e `logo-atlantico.png` para a raiz.
3. Ative GitHub Pages em Settings > Pages > Deploy from branch.
4. Abra o endereço publicado no celular.

## Recursos
- Cadastro de veículos.
- Painel de prazos.
- Coleta de Validador: 24h.
- Coleta de Dados Card: 48h.
- Checagem de Câmera: 7 dias.
- Histórico.
- Exportação para Excel.
- Dados persistidos no `localStorage`.
- Proteção contra saída/voltar acidental.
- Proteção contra gesto vertical acidental no topo da página.
